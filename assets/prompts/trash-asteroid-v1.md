## Intact sprite prompt

Use case: precise-object-edit. Asset type: a tiny low-resolution pixel-art game sprite. Image 1 is the edit target asteroid; image 2 is ONLY a supporting reference for pixel scale and destruction style. Redesign ONLY the single intact asteroid into ONE roughly round compact clump of orbital trash and scrap metal fused together. Recognizable simple crushed tin cans, bent ribbed metal panels, a short bent pipe, and tangled scrap; visually a trash asteroid, not a rock with a few decorations. Preserve the reference's top-down view, irregular squat silhouette, center, very small pixel budget and hard pixel edges. Output ONE intact sprite only, NOT an animation or a sheet. Transparent canvas 96x96 logical pixels. The visible object must occupy only x29..66, y32..64 (38x33 logical pixels), centered at about (48,48) with broad transparent padding. If output resolution is enlarged, render as an exact nearest-neighbor enlargement of that 96x96 logical canvas, with each logical pixel a solid square. All shapes/details must be readable within 38x33 pixels, dark one-pixel contour, flat 2-3 shade clusters, no subpixel details, no antialiasing, no smooth gradients, no lighting glow or ground shadow. Use exactly five opaque colors matching the source: black #000000, deepest plum #2E222F, dark gray-plum #3E3546, mid gray metal #625565, dusty rust highlight #966C6C. The metal should read as angular plates and crushed cans rather than cratered stone. Genuine transparent background alpha zero, no painted checkerboard. No text, no labels, no logos, no stars, no background, no floating debris. One design only.

## Destruction strip prompt

Use case: precise-object-edit. Asset type: pixel-art destruction animation sprite strip for a tiny top-down game hazard. Image 1 is the NEW intact trash asteroid identity reference (a 96x96 transparent frame, object x29..66 y32..64). Image 2 is the ORIGINAL destruction strip to reskin, exactly seven 96x96 frames arranged horizontally in a 672x96 canvas. Replace the rocky pieces in image 2 with the SAME crushed metal cans, bent plates, pipe and ribbed scrap from image 1. Preserve exactly the original seven-frame layout, frame centers (48+96*i,48), sparse progression, coarse one-pixel scale, margins and transparency. Output a SINGLE horizontal 7:1 strip, exactly seven equally sized square cells and ONE row, no grids, no text. Use logical canvas 672x96 (may be displayed as an exact integer enlargement). Frame 1: intact same trash clump 38x33 pixels with thin pale hot cracks. Frame 2: same clump slightly splitting, angular scraps separating, bright orange seams. Frame 3: clump burst into 6 angular chunks including recognizable can end and bent panel, flying outward across middle 70x70 of frame. Frame 4: smaller fast scrap fragments and narrow orange sparks flying farther outward. Frame 5: only a few smaller shards and sparks. Frame 6: 3-4 tiny sparks near outer area. Frame 7: completely transparent empty square. Maintain stable origin and progression with no object crossing cell boundaries. Match supplied reference's tiny economical hard-edged sprite pixels: no smooth shading, no gradients, no anti-aliasing, no glow, no high resolution detailing. Scrap palette matches image 1 exactly: #000000 #2E222F #3E3546 #625565 #966C6C. Sparks may use original reference orange/yellow. Truly transparent background with alpha=0; do not paint black or checkerboards. No stars, no labels, no frame borders. This is ONE model's animation, not seven alternative asteroid designs.
