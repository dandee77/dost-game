## Lifecycle and RNG ledger

| State | Combat world/timers/RNG | Allowed mutation / transition |
|---|---|---|
| New Run | Clear all previous entities/IDs/effects/ledgers, initialize new seed/identity | Fresh build/zero wallet/progress/charge, shield20/20, auto-fire off; preferences/history/seen tutorial remain application-owned |
| Field active | Advance authorized combat slices and owned RNG only on real actions | Damage/loot/progression/score/objectives, ordinary F request after settlement |
| Card / Pause / focus / console | Freeze exact world, clocks, cooldowns, protection, RNG | UI selection/resume only; locked offer stays same; no background passive recovery |
| Station | Suspended field fully frozen, separate hub ship moves | Paid transactions/service timeline; no free repairs/rebuilds. Preview/Cancel no RNG or progression |
| Ordinary retreat / Resume | Same encounter, saved used location, no regeneration/reset | Drain all charge at return; retire set; Resume once with guard/no-offense and fresh Shoot cancellation |
| Campaign clear checkpoint | Finalize earned loot/cards once; retire only cleared arena | Optional station or direct pending encounter; deliberate next launch, no tier/build reset |
| Boss-mode clear | Stop owned hazards/emitter, remove surviving owned adds without reward | One free exit then station; next ordinal advances on later successful launch only |
| Terminal / Ending / Results | Immutable result, no world simulation or rewards | Idempotent save/presentation; Menu/Restart deliberate, no revive. Commit same-step boss credit before result |

Seed every stream from run-seed low/high words plus its domain through seed_seq/mt19937 and unbiased bounded sampling. Domains: natural spawn/variant SPWN0x5350574E; boss bag/placement BOSS0x424F5353; base loot LOOT0x4C4F4F54; Luck LUCK0x4C55434B; cards CARD0x43415244; shop SHOP0x53484F50; portals PORT0x504F5254; ability barrage SKIL0x534B494C. Domain constants go in Config when implemented. The existing fixed-seed prototype owners migrate to this ledger in H01/H03, not an extra RNG singleton. Cosmetic randomness has its own presentation seed and never advances these streams. Finite profile sequences have no weighted random draw. Pausing/drawing/opening panels consumes none. Reset all streams once per fresh run, not per hub visit or rerender. Record seed/rules version in result/debug evidence.

For same-slice mutual death, resolve all already committed projectile/hazard contacts belonging to that simulation slice even if player death is found first; no new player/AI actions after their death timestamp. Then settle objective/source/clear credit and choose one terminal result. Do not discard a committed lethal boss hit because the callback order saw player death first, or manufacture an extra post-death shot/loot collection. Final Campaign completion still needs all required adds resolved in that same slice. Frame-to-frame timing is not automatically simultaneous.

Boss body rendering decision resolves former Q8: each Boss::draw draws its own frame directly after ordinary world Animator sprites in stable instance order; do not also register/draw that body in Animator. Use unique Animator keys for optional death effects only. All bodies/telegraphs use world coordinates, all named HP bars use canvas coordinates. One animation update per owner/frame; this chosen target is not an existing renderer implementation.
